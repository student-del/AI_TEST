# Claude Code 与 Codex 的信息遗忘机制全景

> 讨论问题:Claude 和 Codex 对信息的遗忘,是否只有"LLM 压缩上下文"和"长时间未用删除"两种?
>
> 结论:**远不止。** 遗忘发生在会话内 / 跨会话两个层面,每层多种触发方式;其中真正用到 LLM 的只有一处(Auto-Compact / Compaction),而"时间老化"基本是 Codex 专属——Claude Code 的记忆不做自动时间老化,改用"矛盾即失效"的校验式遗忘。

## 一、遗忘机制全景表

| 遗忘机制 | 层面 | Claude Code | Codex | 靠 LLM? | 可逆? |
|---------|------|-------------|-------|:-----:|:-----:|
| 容量预算卸载 | 会话内 | Tool Result Budget:大结果转磁盘,留 2KB 预览+路径 | 远程 compaction 裁剪超窗调用项 | 否 | 半可逆 |
| 低价值裁剪 | 会话内 | Snip:删空结果/被拒轮次(`Array.filter`) | — | 否 | 不可逆 |
| 时间清除工具结果 | 会话内 | Microcompact 路径B:空闲 60min 后清空旧结果(留最近 5) | — | 否 | 不可逆 |
| 可逆遮蔽/折叠 | 会话内 | Microcompact cache_edits / Context Collapse | — | 否 | 可逆 |
| LLM 语义压缩 | 会话内 | Auto-Compact | Compaction(+物理删助手回复和工具结果) | 是 | 不可逆 |
| 模态剥离 | 会话内 | 图像→`[image]`、文档→`[document]` | — | 否 | 不可逆 |
| 用户主动 | 会话内 | `/clear`、`/rewind`(丢回退点之后历史) | `/clear`、write 开关关闭 | — | — |
| 矛盾覆盖失效 | 跨会话 | 记忆 stale 校验、去重更新 | consolidation 合并/打补丁/丢弃候选 | 部分 | 不可逆 |
| 时间老化 | 跨会话 | 无自动老化(靠校验替代) | 30 天双规则 | 否 | 不可逆 |
| 显式遗忘 | 跨会话 | 用户说"忘掉 X" → 删条目 | — | — | 不可逆 |
| 写入时过滤 | 跨会话 | — | 密钥脱敏、JSON schema 只留匹配内容 | 部分 | 不可逆 |

## 二、五个关键点

1. **会话内的遗忘大多不靠 LLM。** Snip、Microcompact 时间清除、Tool Result Budget、Context Collapse 都是确定性代码;LLM 压缩(Auto-Compact)只是最后一级。"遗忘=LLM 压缩"是常见误解。

2. **可逆 vs 不可逆要分开。** 可逆:cache_edits 屏蔽、Context Collapse 折叠、Tool Result 转磁盘(从视野消失但数据在、能恢复)。不可逆:Snip、时间清除、Auto-Compact 摘要替换。

3. **Codex 的 compaction 也夹带硬删除。** 助手回复和工具结果被物理删除,只对用户消息(20K 内)逐字保留;不只是"摘要"。

4. **Claude Code 记忆不做自动时间老化。** "长时间未用删除"主要是 Codex 的 30 天规则(`max_rollout_age_days`/`max_unused_days`)。Claude 走另一条路:用前校验、冲突即失效改写、去重覆盖、显式遗忘——**按正确性遗忘,而非按时间遗忘**。这是两家记忆哲学的实质差异。

5. **"矛盾覆盖"是独立一大类。** 新事实取代旧事实(Codex consolidation 合并/丢弃;Claude 写新记忆前先查能否更新旧的),旧版本被覆盖即遗忘——既非 LLM 压缩,也非时间老化。

## 三、分类骨架

按"触发源"归纳,遗忘有六大类:

- **容量/预算驱逐**:卸载、裁剪、清除、超窗 trimming(压力触发)
- **可逆遮蔽**:屏蔽、折叠(空间紧张时暂时移出视野,可恢复)
- **LLM 语义压缩**:Auto-Compact / Compaction(唯一用到模型的)
- **矛盾覆盖失效**:新信息取代旧信息(正确性触发)
- **时间老化**:N 天未用即剔除(Codex 专属;时间触发)
- **用户主动 / 写入过滤**:`/clear`、`/rewind`、显式遗忘、密钥脱敏(人或规则触发)

## 四、一句话总结

遗忘不是"两个开关",而是一张多层、多触发的网:会话内(卸载/裁剪/清除/折叠/摘要/剥离/用户回退)+ 跨会话(矛盾覆盖/时间老化/显式遗忘/写入过滤)。**只有一格真正用到 LLM,时间老化基本是 Codex 专属,Claude 更依赖"矛盾即失效"的校验式遗忘。**
